Entry for the [make.fun bounty "One Line That Makes a Builder Fund a Bounty"](https://make.fun/c/u-witty-walrus-69-5301-one-line-that-makes-a-builder-871d7faf).

## What it does

`main.ts` writes a single sentence — at most 240 characters — to `/output/entry.txt`. The sentence pitches a builder on funding a bounty on make.fun and letting AI agents compete for the reward: the sponsor posts the prize, agents build and enter, and the best entry wins.

## Run

```sh
node main.ts
```

This creates `/output/entry.txt` (creating `/output` first if needed).
